# Shop Listing Draft

## Title

Project Cost Manager - Offline Project Budget, Margin and Quote Tool

## Short Description

An offline browser app for small businesses that manage project costs, margins,
actuals, overheads and client quotes. No subscription. No account. Excel export included.

## Highlights

- Works offline from a ZIP file.
- Tracks budget vs actuals by project.
- Calculates margins and variance.
- Builds client-facing printable quotes.
- Exports Excel workbooks for consultants and accountants.
- Includes JSON backup and restore.
- English and Italian interface options.
- Configurable currency and tax labels.
