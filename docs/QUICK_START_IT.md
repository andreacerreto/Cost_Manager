# Guida Rapida - Project Cost Manager

1. Apri `index.html` in Chrome, Edge, Firefox o Safari.
2. Completa la configurazione iniziale: lingua, valuta, imposta, aliquote e dati aziendali.
3. Inserisci le commesse in `Progetti`.
4. Compila costi e ricavi previsti in `Budget`.
5. Compila costi e ricavi effettivi in `Consuntivo`.
6. Controlla margini e scostamenti in `Dashboard` e `Varianze`.
7. Crea preventivi stampabili in `Preventivi`.
8. Usa `Esporta Excel` per condividere i dati con consulenti.
9. Usa `Backup JSON` per salvare una copia completa ripristinabile.

I dati restano sul dispositivo. Fai backup JSON con regolarita.
